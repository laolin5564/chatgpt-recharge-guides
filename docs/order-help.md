# 查单与异常处理

更新日期：2026-10-10

会员购买经过付款确认、商品交付和正式兑换。支付渠道扣款，不等于商城已确认收款；商城「已交付」，也只代表本单内容已经生成。先定位卡在哪一步，再选查询入口。完整的步骤与配图见[商城订单图文帮助](https://shop.laolin.ai/shop/guides/order-help)。

## 商城订单与充值任务在哪里查

| 要查询的内容 | 页面 | 所需资料 |
| --- | --- | --- |
| 付款、交付、领取兑换码、退款 | 商城「订单查询」 | 下单邮箱与查询密码 |
| 充值卡密是否正式提交 | 兑换页「卡密查询」 | 本单完整兑换码 |
| 正式提交后的充值结果 | 兑换页「进度查询」 | 兑换时使用的原卡密 |

商城订单号对应购买，兑换页订单号对应充值任务。下单邮箱与充值账号可以不同，保留各自的原记录，才能核对付款、交付和账号处理之间的关系。

## 用下单邮箱和查询密码找具体订单

在「订单查询」中填写下单「邮箱」和当时设置的「查询密码」，点击「查询订单」。查询密码不是 ChatGPT、邮箱或支付密码。匹配多笔订单时，按商品名称、创建时间和订单号选择对应记录，才会展开这笔「订单详情」；有分页时继续用「上一页」「下一页」。

找不到时，检查邮箱拼写，以及查询密码的大小写和原有空格。同邮箱用不同查询密码下单，结果也会不同。「本次会话」只显示当前浏览器保存的部分近期记录，不是完整历史；换设备后仍应使用邮箱和查询密码。

当前查单页没有自助找回查询密码的入口。确实忘记时，保留已有订单号和支付凭证，通过商城页面的售后方式说明情况；不要在公开仓库贴密码或个人付款资料，也不能据此保证查询权限一定能恢复。

## 下单后断网：先恢复原请求

点击「立即下单」后结果没返回，不能直接判断没成单。在原商品页看到「上次提交结果未知」时，用「恢复提交结果」。也可以点「前往恢复中心」，在订单页「待恢复请求」中找到这一条，点击「恢复结果」。这些入口继续确认首次提交的结果，避免重复成单。

已成单可以直接恢复；需要继续提交时，填写首次使用的查询密码，不要临时更换。「移除未成单请求」只在已明确未成单时提供，作用是删除本地记录。删除记录不是取消服务器订单，也不会撤销付款。

## 已付款但没有拿到卡密

在原「订单详情」点击「刷新」，查看「在线支付」和订单状态。付款记录已扣款，但商城尚未显示「已确认收款」，且页面仍有「核对支付结果」时，点击它核对原付款。显示「支付结果待核查」时，保存原交易号和订单号等待结果，不要另建订单重新付款。

已确认收款且支持自动交付的订单，会显示「待自动发卡」。出现自动发卡暂时受阻的说明时，原单仍保留已收款状态，系统继续处理；这时需要关注交付，不是再次付款。人工交付商品查看本单「交付说明」和店铺联系方式。

「已交付」后，会员码在「充值兑换码」区域领取，点「去兑换」继续充值；普通商品查看「交付内容」，需要时点「复制交付内容」。未收到邮件时，也先看订单里是否已经有交付内容。没有适用于所有商品的固定到账分钟数。

## 卡密已用或关闭充值页，查询原结果

回到兑换页「进度查询」，输入兑换时使用的原卡密，点「查询进度」。这个入口查原任务，不需要重新粘贴 Session，也不会再次充值。记录商品、充值邮箱、「更新时间」和原消息；临时不能更新，不等于充值失败。

不确定是否正式提交过，可先用「卡密查询」。「尚未提交兑换」表示尚无正式任务，读取账号不是充值已经开始。「处理中」「待核查」继续查原单；即使有「兑换另一张」，也不能理解为原任务已取消。出现「账号信息已失效」且提供「重新验证卡密」时，再重新验证原码并取得最新资料。

## 充值成功却仍显示免费或余额不符

先确认成功是在兑换页，不只是商城「已交付」。再核对 ChatGPT 账号设置里的实际邮箱和登录方式；Apple 隐藏邮箱可能使用中继邮箱，不能只凭头像判断。确认是同一账号后，刷新或重新登录查看套餐。购买点数则核对对应余额，不应期待会员档位改变。[OpenAI 的账号套餐核对说明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)

## 联系售后时提供具体证据

用一句话说明阶段，例如「付款渠道已扣款，商城仍待核查」或「商城已交付，兑换页待核查」。通过商城售后提供：

- 商城订单号、商品及问题发生时间。
- 已付款时的原支付交易号，商城当前支付和交付状态。
- 已兑换时的原任务结果、页面显示的订单号、充值账号及完整错误提示。

常规核对先提供订单和状态，截图遮住完整卡密、Session、密码与验证码，不要将个人资料上传公开 Issue。若原失败充值任务明确提供专门售后邮箱，并要求兑换卡密与完整 Session，核对原任务和邮箱后，仅通过页面「发送邮件」入口私下处理，不发到公开群聊或截图中。

退款要核对原收款、交付和兑换状态，由管理员按原单处理；成功会员充值不能按未使用码处理。退款处理中或待核查也不是已经到账，继续关注原结果。
