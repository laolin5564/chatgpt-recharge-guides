# 查单与异常处理

检查日期：2026-10-09

找不到交付内容时，先查询原订单。重新买一份同商品不会帮助确认原付款和原交付，反而可能多出一笔需要处理的订单。

## 使用下单时的邮箱和查询密码

商城查单使用下单时填写的邮箱与查询密码。查询密码是订单查询资料，不是你的 ChatGPT 登录密码。检查邮箱拼写、空格、密码大小写，尽量按下单时保存的记录填写。

可以从[订单帮助](https://shop.laolin.ai/shop/guides/order-help)进入当前查单页面。同一邮箱与查询密码下可能有多笔订单，找到与你的商品、时间和金额对应的那一笔，不要只查看列表第一项。

## 先分清问题出在哪个阶段

| 阶段 | 先核对的内容 | 下一步 |
| --- | --- | --- |
| 付款 | 原订单是否记录收款结果，支付平台是否实际扣款 | 只返回原订单查看；有扣款但订单未更新时联系商城 |
| 交付 | 原订单是否出现交付内容或处理中提示 | 阅读原页面提示，不把付款成功直接当作已领到码 |
| 兑换 | 是否拿到兑换码、是否已正式提交、原任务是什么结果 | 查看原任务；进行中或待核查时先处理原结果 |

关闭支付窗口、刷新页面或重新打开查单，不等于支付失败；同样，支付平台有一笔扣款，也不能仅据此推断会员充值已经完成。

## 联系时提供最少必要的信息

通过商城页面列出的联系入口，说明订单号、商品、下单时间、你看到的状态和问题经过。如果需要截图，先遮住卡密、查询密码、完整邮箱、账号登录资料和完整支付信息。

忘记查询密码时，不要在公开仓库留言尝试找回，也不要提供 ChatGPT 登录密码。通过商城联系入口说明你能提供的原付款依据，由商城根据原订单处理；本资料不承诺存在自助找回入口或一定符合退款条件。
