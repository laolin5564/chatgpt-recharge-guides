# 已有订阅与账号资料

更新日期：2026-10-10

已有会员再次购买前，先确认这次是续同档、换套餐，还是补充某项功能的用量。具体步骤和配图见[商城续费升级图文指南](https://shop.laolin.ai/shop/guides/renewal-upgrade)；这份资料帮助你决定先查什么，不代替本单商品条件与实时账号结果。

## 核对当前订阅和原渠道

在目标 ChatGPT 账号设置核对实际邮箱与当前套餐，再到原购买渠道查看订阅。网页、Apple 和 Google Play 的订阅需要在对应渠道管理。付款失败、已申请取消、当前周期未结束和已经降为免费，是不同状态；一个到期日期不足以判断能否新购或升级。

原渠道可能仍管理续订。卸载应用不会取消订阅，扣款失败也不一定表示原订阅结束；在多个渠道同时订阅可能重复收费。更换渠道前，先核对原订阅和扣款状态。[OpenAI：避免跨渠道重复订阅](https://help.openai.com/en/articles/20001043-how-do-i-avoid-being-charged-twice-if-i-subscribe-to-chatgpt-on-ios-android-and-the-web)

## 按账号状态与目标选择下一步

新购办理目标套餐，续费处理后续订阅，升级变更当前档位，点数加购补充符合条件的功能用量。普通套餐码、账号专用升级码和点数码不能互相替代；也不能默认提前买码能叠加剩余时长或马上重置全部额度。

| 当前情况 | 目标 | 先做什么 |
| --- | --- | --- |
| 当前会员仍生效 | 续同档或换更高档 | 查原渠道续订状态与目标商品说明，再取得最新 Session；不要直接当作新购 |
| 已取消，但当前周期未结束 | 更换购买方式 | 确认生效周期和后续扣款状态，不能把取消等同于已免费 |
| 某个工具用量达到上限 | 继续使用该功能 | 查对应重置时间与点数选项，先分清补用量还是换会员 |
| 账号读取显示「未提供」 | 判断是否能充值 | 到官方账号设置核对订阅；字段缺失不是资格证明 |
| 兑换页显示宽限期 | 再充值会员 | 停止提交，核对实际结束信息；结束后重新取得账号资料 |
| 原充值待核查 | 再买一档或再充一次 | 先查原任务并联系售后，原结果未明确前不另起充值 |

这张表不是资格清单，不会把某种当前套餐一律判为可升级。普通商品售价也不等于已有会员的升级报价，剩余时长是否抵扣要看本单实际路径，不能自行按比例推算。

## 会员到期、Session 过期和宽限期结束不同

| 时间或提示 | 对应问题 | 下一步 |
| --- | --- | --- |
| 原渠道的会员周期或到期日 | 原订阅周期安排 | 与当前套餐、取消及续订状态一起核对 |
| 「账号信息已过期，请返回重新获取」 | 当前读取的账号资料已不适用于继续提交 | 点「更换账号」返回，重新取得完整 Session 后读取 |
| 「宽限期结束」 | 实际查询返回的宽限期截止时间 | 看清北京时间；无时间不自行推算，时间过后仍重新读取最新资料 |

Session 登录有效期不能当作会员到期日，某个工具的额度重置也不代表会员到期。日期不一致时，先核对各字段含义和实际账号，不把网上固定天数套在自己的账号上。

## 「等待宽限期结束」的实际操作

「确认充值账号」检测到明确宽限期时，页面显示阻断说明，确认按钮变为不可用的「等待宽限期结束」。此时尚未正式提交，读取账号本身没有使用卡密；保留原码，不要删改 Session、反复点击或换另一张码绕过同一账号状态。

1. 核对页面展示的是目标账号，保存原卡密及宽限期提示。
2. 查看「宽限期结束」一栏。有真实截止时间时按北京时间显示；未取得时显示「暂未获取，请稍后重新读取」，不能据此猜日期。
3. 截止时间过去后，点「更换账号」返回填写页，在同一目标账号重新打开「获取账号信息」，复制完整新内容并粘贴，等待自动读取；尚未开始可点「下一步」，失败后检查内容并用「重新读取」。
4. 再次核对邮箱、套餐和订阅状态。新的结果仍有阻断就继续停止；只有允许提交且信息正确，才勾选账号确认框继续。

「更换账号」也可以用于真正换号，但账号专用升级码仍须遵守本单绑定限制。不能用另一邮箱试用，也不要手改 Session 里的邮箱。

## 正式确认与原单结果

「确认充值账号」展示邮箱、「当前套餐」「订阅状态」和「充值商品」，用于核对，并不是实时资格检查已全部完成。确认正确且没有阻断后，勾选「我已核对账号，确认充值到此账号」，点「确认充值」，才进入真实准备和任务处理。

准备时被拒绝，保存完整提示核对商品和账号。已提交后显示「处理中」「待核查」或「需要处理」，用原卡密在「进度查询」点击「查询进度」，不再买另一档覆盖问题。明确出现「账号信息已失效」并提供「重新验证卡密」时，再走原码重新验证入口。成功后，到同一账号核对实际套餐或对应点数。

## Session 只用于你核对过的指定入口

Session 是敏感会话资料，商城会加密保存并在履约时转交服务。提交前核对地址，不将原文放进 GitHub Issue、评论、Gist、截图或仓库示例。常规求助先提供原订单号、状态和错误提示，遮住完整卡密、Session、密码与验证码；专门失败任务售后明确要求资料时，仅向该原任务页面提供的售后邮箱私下处理。

怀疑泄露时，按[OpenAI 账号安全说明](https://help.openai.com/en/articles/8304786-keeping-your-openai-account-secure)检查活动会话和未授权访问。更详细的资料处理范围见[商城账号与 Session 帮助](https://shop.laolin.ai/shop/guides/account-session)；原订单异常按[查单与异常处理](order-help.md)准备记录，不在公开讨论中贴凭据。
