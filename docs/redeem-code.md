# 兑换码使用与账号核对

更新日期：2026-10-10

这篇适用于老林商城交付的会员充值兑换码。它是商城的交付凭证，不是 ChatGPT 登录密码，也不能当作 OpenAI 官方礼品卡。库存卡密、人工交付和点数商品各有自己的用途，先确认本单商品与交付说明。

完整的页面步骤与配图见[商城兑换图文指南](https://shop.laolin.ai/shop/guides/redeem-code)。下面按领取、读取账号和正式提交三个阶段说明关键操作。

## 先分清你手里的资料

| 资料 | 使用位置 | 用途 |
| --- | --- | --- |
| 下单邮箱、查询密码 | 商城「订单查询」 | 找到付款状态与本单交付内容 |
| 充值兑换码 | 兑换页「立即兑换」「卡密查询」「进度查询」 | 开始兑换或查询原结果 |
| 完整 Session | 兑换页「账号信息」 | 读取并确认目标 ChatGPT 账号 |

联系邮箱不直接指定充值账号，查询密码也不是 ChatGPT、邮箱或支付密码。已有会员时，先查看当前套餐和原订阅渠道；普通套餐码、账号专用升级码与点数码不能仅凭名字相近就互换。

## 从订单详情领取兑换码

1. 打开商城「订单查询」，填写下单邮箱和查询密码，点击「查询订单」。
2. 在「匹配订单」中按商品、时间和订单号选中本单，打开「订单详情」。
3. 显示「已交付」后，找到「充值兑换码」，保存本单卡密并点击「去兑换」。

「已确认收款」表示商城已确认付款，「已交付」表示本单内容已经生成，两者都不等于会员已开通。仍为「待自动发卡」时，保留原订单等待交付，不要再付款一次。普通商品显示的是「交付内容」，不能把它直接当作会员充值码。

## 输入卡密，确认充值商品

在兑换页「立即兑换」中，将完整卡密填进「兑换卡密」，点击「下一步」。接下来「填写充值账号」会展示「充值商品」，先核对它与购买商品一致。

只想检查卡密状态时，用「卡密查询」中的「查询卡密」。「尚未提交兑换」表示还没有正式充值任务，不能把读取过卡密或预览过账号当成已经充值。已经提交过的，应到「进度查询」查原结果。

## 取得完整 Session，再确认账号

1. 点击「登录充值账号」，在自己的浏览器中确认登录的是准备充值的账号。
2. 点击「获取账号信息」，复制页面全部内容，粘贴到兑换页「账号信息」。不要只复制邮箱或某个 Token。
3. 等待自动读取；尚未开始时可点「下一步」，失败后检查完整内容并使用「重新读取」。
4. 在「确认充值账号」中核对邮箱、「当前套餐」「订阅状态」和「充值商品」。邮箱有误，点「更换账号」，回到 ChatGPT 切换账号后重新取得资料。
5. 无阻断且信息正确时，勾选「我已核对账号，确认充值到此账号」，再点「确认充值」。

Session 含敏感凭据，商城会加密保存并转交履约服务。不要把原文贴进公开群聊、评论、GitHub Issue 或截图，也不要手改里面的邮箱或订阅字段。「未提供」表示缺少对应资料，不证明会员已到期或账号一定可充。账号预览本身不使用卡密，也不保证正式充值资格。

确认按钮不可用时，检查账号确认框、读取出的邮箱、账号信息有效期和阻断原因。提示宽限期时，先看[已有订阅与账号资料](renewal-and-account.md)，不要反复点击绕过。

## 正式提交后，查询原任务

进入「充值进度」后，查看结果标题、商品、充值邮箱和「更新于」。关闭页面后，在「进度查询」输入原卡密，点击「查询进度」即可查询原任务；不需要再次提交 Session，也不会再次充值。

| 结果 | 下一步 |
| --- | --- |
| 处理中、排队中、充值中 | 保留原卡密，继续查询同一个任务 |
| 待核查、需要处理 | 记录原提示，通过商城售后核对，结果未明前不另行充值 |
| 账号信息已失效 | 出现「重新验证卡密」时，重新验证原码并取得最新账号信息 |
| 充值成功 | 到同一 ChatGPT 账号核对实际套餐或相应余额 |
| 充值未完成 | 保存原失败原因与订单信息，通过页面展示的售后入口处理 |

「兑换另一张」只是返回输入入口，不会撤销先前任务。如果成功结果与账号显示不一致，先核对实际账号邮箱和登录方式，再刷新或重新登录；仍不一致时按[查单与异常处理](order-help.md)准备原记录。截图遮住完整卡密与 Session。
