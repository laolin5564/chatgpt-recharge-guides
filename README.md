# ChatGPT 会员、点数与兑换使用指南

这份中文资料帮助你在购买和兑换前核对商品、账号与订单，区分会员订阅、使用点数及 API 计费，并在遇到付款、交付或兑换问题时找到合适的处理入口。

资料由老林商城独立维护；OpenAI 的产品能力、账号资格与计费规则以其当前官方说明及账号实际页面为准。文档中的操作说明不能代替当次页面返回的账号状态、商品条件或订单结果。

## 文档如何维护

每篇说明标明检查日期。容易变动的套餐能力、可售商品、价格和资格不固定复制到仓库；读者应通过实际商品说明和官方资料确认。发现内容过时，可按[更新规范](CONTRIBUTING.md)提出具体改进。

公开讨论只用于修正文档，不用于处理个人订单。不要上传邮箱、查询密码、卡密、登录资料或支付凭证；订单问题请使用商城页面列出的联系入口。
